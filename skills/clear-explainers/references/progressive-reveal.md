# Progressive Reveal

## Principle

Reveal one relationship at a time while keeping the anchors needed to compare states.

## Use when

- simultaneous complexity exceeds useful attention;
- object continuity makes change meaningful;
- stepwise emphasis guides a causal or conceptual chain;
- optional detail can follow a complete overview.

## Reject when

- prior values disappear before comparison;
- scrolling controls critical timing unpredictably;
- transitions move unrelated objects and break identity;
- the only complete state exists momentarily;
- mobile reordering changes the argument.

## Prefer instead

Keep axes, baselines, key labels, and reference objects stable. Use explicit step titles and progress when sequence matters. Allow back/replay. Offer a static summary or final state that preserves the complete claim.

## Escape conditions

- Replace transitions with simultaneous before/after when exact difference matters more than process.
- Remove animation under reduced-motion preference without removing the explanatory relationship.
- A single surprising reveal can work when readers already possess the comparison anchor.

## Audit signals

- change blindness risk across cuts;
- scroll position and narrative state desynchronize;
- labels flicker or reassign identity;
- reader must remember a prior filter or scene;
- no recovery after refresh/deep link.
