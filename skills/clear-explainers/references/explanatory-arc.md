# Explanatory Arc

## Principle

Sequence the minimum claims needed to move the audience from its likely starting model to the target model.

## Use when

- concepts have prerequisites;
- mechanism matters more than a single result;
- evidence and interpretation must be distinguished;
- misconceptions need explicit correction.

## Reject when

- scenes follow data collection order rather than learning dependency;
- a dramatic opening overstates later evidence;
- the explanation introduces terms after using them;
- caveats capable of reversing the claim appear only at the end;
- chronology is mistaken for causality.

## Prefer instead

Use a spine: question → prior model → key distinction → evidence → mechanism/interpretation → limits → implication. Remove scenes that add no new relationship. Place the strongest falsifying caveat before the action/claim it qualifies.

## Escape conditions

- Experienced audiences may start from the exception or decision and drill backward.
- Mystery/reveal can motivate learning when it does not conceal material evidence.
- A reference explainer may support non-linear entry points if each path restores prerequisites.

## Audit signals

- reader cannot summarize what changed between scenes;
- conclusion precedes evidence with no signposting;
- terms or encodings change meaning mid-story;
- final recommendation cannot be traced to a displayed claim.
