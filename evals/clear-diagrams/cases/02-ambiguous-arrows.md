# Case: arrows mean everything

**Family:** Audit

## Prompt

Audit an architecture diagram where identical arrows mean API calls, database writes, deployment dependency, and user navigation. A legend says only “connection.”

## Expected skill behavior

- Flag edge semantics as the root comprehension/integrity problem.
- Reduce the view to its primary question or create typed layers/views.
- Label or style materially different relationships locally.
- Avoid merely changing arrow colors without defining meaning.
