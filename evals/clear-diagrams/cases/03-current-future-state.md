# Case: current and future state collapse

**Family:** Audit

## Prompt

A system map shows deployed services and proposed services with identical boxes. Leadership is using it to approve migration risk. Audit it.

## Expected skill behavior

- Treat truth status as a critical boundary.
- Distinguish current, proposed, transitional, and unknown states explicitly.
- Preserve dependencies that affect migration risk.
- Avoid implying deployment from visual presence.
