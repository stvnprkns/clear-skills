# Case: rainbow categories

**Family:** Audit

## Prompt

A bar chart has 14 categories. Every bar uses a different bright color and a legend underneath. Category names are already printed on the y-axis. There is one category that matters to the decision. Audit it.

## Expected skill behavior

- Identify redundant categorical color and detached legend as unnecessary decoding.
- Recommend neutral bars + one emphasis color for the focal category.
- Preserve direct y-axis labels and remove the redundant legend.
- Mention non-color cue only if focal state would otherwise depend exclusively on color.
