# Case: should be a table

**Family:** Rethink / Create

## Prompt

I need a visualization for procurement. Users look up 18 vendors and need exact contract value, renewal date, SLA tier, owner, risk status, and current discount. What chart should I use?

## Expected skill behavior

- Recommend a table as the primary representation because lookup and multi-field exact retrieval are the task.
- Suggest lightweight inline visual encoding only where useful (risk status, bar-in-cell, sparkline) rather than inventing a dashboard of charts.
