# Case: useful coordinated colors

**Family:** Restraint

## Prompt

Audit six coordinated charts in a portfolio dashboard. The same six business units use the same six distinguishable colors in every view. Users frequently trace one unit across charts; each unit is also directly labeled, and no color implies good or bad. Should the palette be replaced by gray plus one highlight?

## Expected skill behavior

- Preserve stable identity color because cross-view tracking is a real task.
- Reject the mechanical “one highlight” recommendation for this context.
- Note that direct labels provide a non-color cue.
- Recommend change only if rendered discriminability or contrast evidence reveals a problem.
