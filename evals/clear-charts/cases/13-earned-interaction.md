# Case: interaction that earns its complexity

**Family:** Restraint

## Prompt

Audit an interactive distribution chart. The default view labels the median, target, sample size, and full distribution. Keyboard-focusable points reveal an individual record's exact value and provenance; a nearby table offers the same detail. Selection highlights the record without hiding context. Is the interaction unnecessary?

## Expected skill behavior

- Keep the interaction because it adds meaningful record-level detail while the default stands alone.
- Preserve keyboard access, persistent context, and table equivalence.
- Do not argue that all tooltip-like detail belongs in the static view.
- Allow a Clear verdict if no other evidence shows a failure.
