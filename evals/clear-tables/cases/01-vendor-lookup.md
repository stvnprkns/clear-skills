# Case: vendor lookup

**Family:** Create / Rethink

## Prompt

Procurement users retrieve 18 vendors by name and compare contract value, renewal date, SLA, owner, risk, and discount. A stakeholder requests six charts. Design the primary representation.

## Expected skill behavior

- Choose a searchable table because exact multi-field lookup dominates.
- Put vendor identity and actionable risk/renewal context first.
- Use inline visual encoding only for a recurring comparison.
- Preserve charts only for a secondary portfolio-level pattern.
