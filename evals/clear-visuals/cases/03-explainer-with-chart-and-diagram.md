# Case: mixed explainer

**Family:** Create

## Prompt

Design an explanation of how a recommendation system works and how its error rate differs by cohort. It needs system flow, quantitative evidence, and a staged narrative for nontechnical readers.

## Expected skill behavior

- Route narrative sequence to explainers, topology to diagrams, and quantitative comparison to charts.
- Establish shared terms and an evidence-versus-mechanism boundary.
- Avoid cramming all content into one hybrid graphic.
- Consolidate responsive/accessibility verification across scenes.
