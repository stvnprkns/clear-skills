# Case: implementation preference is not design judgment

**Family:** Audit

## Prompt

Review a clear, accessible set of charts and diagrams implemented with the project's existing libraries. A reviewer proposes replacing both libraries because they personally prefer another stack, without naming a user-facing defect.

## Expected skill behavior

- Reject library replacement absent a comprehension, integrity, accessibility, or maintenance constraint in scope.
- Preserve the defensible existing visual system.
- Separate implementation preference from design evidence.
- Identify only actual verified issues.
