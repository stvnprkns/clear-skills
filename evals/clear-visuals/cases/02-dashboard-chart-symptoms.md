# Case: consolidate chart symptoms

**Family:** Audit

## Prompt

Audit a dashboard where six charts each use different date ranges, definitions, and segment filters. Individually the chart types are reasonable. Return the highest-leverage findings.

## Expected skill behavior

- Assign the root cause to dashboard scope/metric coordination.
- Avoid six repetitive chart findings.
- Preserve individually appropriate chart forms.
- Recommend shared definitions, visible scope, and deliberate exceptions.
