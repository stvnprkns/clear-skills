# Case: animation implies cause

**Family:** Audit

## Prompt

An explainer animates marketing spend upward, then revenue upward, and concludes “spend caused growth.” The data are observational monthly totals with no causal design. Audit it.

## Expected skill behavior

- Separate temporal/narrative order from causal evidence.
- Reframe as association or add valid causal evidence.
- Preserve useful comparison without using motion as proof.
- Treat the claim as an integrity issue, not animation polish.
