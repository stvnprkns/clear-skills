# Case: novice and expert paths

**Family:** Create

## Prompt

Design an explainer for a forecasting model. New users need the basic mechanism; experts need assumptions, residuals, and sensitivity. A single linear story is either overwhelming or incomplete.

## Expected skill behavior

- Build a coherent novice default with optional expert depth.
- Preserve shared definitions and provenance.
- Reveal caveats before decisions they could reverse.
- Avoid two disconnected explanations with drifting terminology.
