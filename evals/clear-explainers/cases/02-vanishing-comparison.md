# Case: progressive reveal erases anchors

**Family:** Audit

## Prompt

A six-scene scrollytelling piece replaces the chart completely at each step. The conclusion requires comparing scene two with scene six, but readers cannot go back and values are unlabeled. Audit it.

## Expected skill behavior

- Identify serial memory and lost anchors as the root problem.
- Persist or juxtapose the required comparison.
- Add navigation/replay or a complete summary state.
- Avoid merely slowing the animation.
